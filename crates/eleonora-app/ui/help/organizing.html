Moving, copying, and deleting

  • Transfer To… (Ctrl+Shift+T, Transfer on the toolbar): type part of a folder's name to find it in any account, then Enter. The arrow keys open and close folders in the list.
  • Copy To…: the same, keeping the message where it is too.
  • Transfer ▸ To a New Mailbox…: makes a folder and moves the messages into it.
  • Delete (Ctrl+D or the Delete key): moves the messages to the account's Trash (Deleted Items in Microsoft 365).
  • Edit ▸ Undo (Ctrl+Z) moves them back.

Moves happen in Eleonora at once and are made on the server in the background, even if you're offline at the time. A move between two accounts is a copy: the original stays on its own server.

These work on a selection of many messages, and on search results (each message from its own folder).

Saving messages as files (.msg and .eml)

Drag messages from the message list onto your desktop or into a folder in File Explorer (the Finder on a Mac) to save them there as files, each named by the message's date and time and then its subject, as 202504211530 Re Whatever (year, month, day, hour, and minute in your computer's time), so the files sort by date and two messages with the same subject don't clash. Colons are left out of the subject, and slashes become dashes, as Windows doesn't allow them in a file name. The date is the one the message list shows, else when the message came into Eleonora, so every file has one. Select several first (Ctrl+click, Shift+click, Ctrl+A) and drag any of them to save them all.

  • Drag: Outlook's .msg files, which Outlook and most legal and archiving tools open.
  • Hold Ctrl or Shift while dragging: .eml files, the original message exactly as Eleonora received it, byte for byte. Outlook, Eleonora, and other mail programs open these too.

Eleonora writes the files in the background, with the count on the status bar ("Writing messages as .msg files: 120 of 400"), so you can carry on meanwhile. The drag starts once they're written. If you let go of the mouse before that, Eleonora asks which folder to put them in.

Which to use as evidence

An .eml is the message itself: the same bytes the mail server delivered, so it can be checked against a copy kept anywhere else, and a digital signature on it still checks. Use .eml when the exact original matters.

A .msg is what Outlook saves: the message as Outlook's own fields, not its original bytes. Outlook's own .msg files are made the same way, because Microsoft 365 converts every message into those fields when it arrives. Eleonora writes a .msg the way Microsoft 365 and Outlook do:

  • The message's header block is kept word for word (every Received line, the authentication results, the Message-ID), as Outlook keeps it. In Outlook it's under File ▸ Properties ▸ Internet headers.
  • Every attachment is kept byte for byte. A forwarded message attached to it is kept as a message inside it.
  • The text and the HTML are kept as text and HTML. Their encoding may change (Eleonora writes the HTML as UTF-8), so the words are the same but the bytes may not be.
  • A message that's digitally signed or encrypted (S/MIME) is kept whole and unchanged inside the .msg, as Outlook keeps one, so its signature can still be checked.
  • A message from the Online Archive is written from Exchange's own copy of it, the one Eleonora keeps when Keep original messages exactly is on: the fields exactly as Microsoft holds them.

Every file Eleonora saves is marked as downloaded from the Internet, as attachments are.

Programs and scripts can save messages the same way: eleonora-cli call v1.mail.save_as '{"ids": [123, 456], "dir": "C:/Evidence", "format": "eml"}' (format msg or eml). See the local API.

Exporting to a folder: Export as .eml or .msg Files…

For many messages at once, or a whole search (for legal discovery, archiving, or records), choose them (click, Ctrl+click, Shift+click, or Ctrl+A for every one in the list), then right-click one of them and choose Export as .eml or .msg Files…, or choose File ▸ Export ▸ Messages as .eml or .msg Files… (in the Outlook-style, Thunderbird-style, Gmail-style, and Yahoo-style looks, Export Messages as .eml or .msg Files… in their File or Mail menu). With search results shown and only some of them chosen, Eleonora asks whether to export just the chosen ones or every message the search found. Pick .msg (Outlook) or .eml (the original message byte for byte), then the folder. Eleonora writes the files in the background; the status bar counts them as it goes ("Saving messages as .msg files: 1,200 of 4,000 (1,180 written, 20 duplicates skipped)…"), and a summary says what was done when it ends.

Duplicates are skipped and counted: a message chosen twice, a second copy of the same message (the same Message-ID, kept in two mailboxes), and a message whose file is already in the folder exactly as it would be written (saved there before). So saving the same search into the same folder again writes only what's new. A message that can't be written is named in the summary with why.

Making, renaming, and deleting mailboxes

  • Make one: Mailbox ▸ New Mailbox…, or right-click an account (New Mailbox…) or a folder (New Mailbox Inside…). Type "/" in the name for levels, such as Projects/2026.
  • Rename: right-click the folder, Rename….
  • Delete: right-click the folder, Delete…. The folder, its mail, and its folders go into Deleted Items (or Trash), as Outlook does. A folder already in the Trash is removed only when it's empty.

Each change is made on the server too (Microsoft 365, IMAP, Gmail labels). The server's own folders (Inbox, Sent, Drafts, Deleted Items, Junk, Archive) and the Online Archive's can't be renamed or deleted. A folder renamed in Outlook or on your phone takes its new name in Eleonora too.

Some folders Microsoft 365 keeps for itself hold no mail: PersonMetadata (the People app's data about your contacts), ExternalContacts, and Yammer Root (Viva Engage). Eleonora neither downloads nor shows them. Outlook on the web may still list them.

Status, priority, and labels

Status

Message ▸ Change Status: Unread, Read, Replied, Forwarded, Redirected. Read and unread reach the server.

Priority

Message ▸ Change Priority: Highest to Lowest, Raise, Lower, or As the Message Says. High priority shows as a flag on IMAP servers and as a star in Gmail.

Labels

Message ▸ Change Label…: tick the labels the message should carry (press 1–9 to tick quickly), or None. A message can carry several. Labels show as colored chips in the list.

In Microsoft 365 mailboxes, labels are Outlook's categories with the same names, so Outlook and your phone show them too. On IMAP servers they're keywords.

Edit the list in Settings ▸ Mail ▸ Labels (or Edit Labels… in the Change Label window). Renaming a label renames it on its messages. The list travels to your other computers.

Emptying the Trash

Special ▸ Empty Trash… lists each account's Trash with how many messages it holds, and asks before doing anything.

  • Microsoft 365: deleted from Deleted Items on the server. Exchange still keeps them in Recoverable Items for a while, as when you empty Deleted Items in Outlook.
  • IMAP: deleted on the server.
  • Gmail: left in Gmail's Trash, which Gmail empties after 30 days (so a mistake can still be undone there).
  • The Online Archive's Deleted Items are never touched.

Messages that were only in the Trash leave the library. Their space comes back at the next maintenance.

Opening .eml, .msg, .ics, and .vcf files, and mail links

Double-click a .eml message or an Outlook .msg file and it opens in Eleonora's message viewer: a small program of its own, so it shows in about half a second, whether or not Eleonora's window is open, and never waits for your library or its downloading. Each file opens in a viewer of its own; close it with Esc. The file isn't added to your library (to add files, use Import).

The viewer shows the message with its sender, recipients, date, and attachments, and has tabs for the Text, the Headers, and the Source (for a .msg, the internet message Eleonora made of it). Its buttons:

  • Reply (Ctrl+R), Reply All (Ctrl+Shift+R), and Forward (Ctrl+F) start a new message in Eleonora's window (which opens if it isn't running), with the message quoted or attached as usual.
  • Save as .eml (Ctrl+S) saves the message as an .eml file in a folder you choose.
  • Print (Ctrl+P) prints it with its header lines.
  • Click an attachment to open it with its program, or its arrow to save it; Save All… saves every one.

The same safety as Eleonora's window: the message can't run scripts or load anything from the internet. Pictures from the web show only when you click Show pictures, or by themselves for senders on your always-show list (Pictures from the web). A message that looks like a fraud is marked in red, its links don't work, and its pictures and attachments aren't opened, with no way to turn that off. Attachments that are programs are never opened (save one only if you trust it), and every file the viewer saves is marked as downloaded from the internet, so Windows and Office treat it with care. The viewer reads your library's whitelist and always-show list when it can do so at once; when it can't, it trusts no one and asks about pictures every time.

A .msg is Outlook's own kind of file (properties, not the message as it came). Eleonora turns it back into an internet message: the header block exactly as Outlook kept it, the text, the formatted (HTML) text (also when Outlook kept it only inside rich text), every attachment byte for byte, forwarded messages as messages, and a signed or encrypted message whole. From a command prompt, eleonora-cli msg-to-eml FILE.msg writes the same .eml beside it (--json describes it instead); eudora FILE.msg opens the viewer.

File ▸ Open File… (Ctrl+O) in Eleonora's window opens an .eml in a message window there, as if it were in your library.

A .ics calendar file opens in a window listing its events: time (in your time zone), place, organizer, people, and notes. Add to my calendar puts an event on one of your calendars without inviting its people.

A .vcf contact card (a vCard, one contact or a whole address book) opens in a window listing each contact in it: name, company, email addresses, phone numbers, and addresses. Eleonora looks for each one in your address book by its email addresses and phone numbers:

  • Already there: Update it. The contact takes the file's values where the two differ and keeps every email address, phone number, address, and note it already had. Or Add as a new contact anyway.
  • Not there yet: Add to contacts, into the address book chosen at the top (the one you used last, at first).
  • A file of several contacts also has Add all new and Update all already there, each asking first.

The change is made in Eleonora at once and on the contact's server (Microsoft 365, Google, or CardDAV) with the next check.

To make Eleonora open these files, on Windows right-click one, choose Open with ▸ Choose another app ▸ Eleonora ▸ Always once for each kind (.eml, .msg, .ics, .vcf), or set them in Settings ▸ Apps ▸ Default apps ▸ Eleonora (Windows lets no program make itself the default). On the Mac, use the Finder's Get Info ▸ Open with ▸ Change All….

Mail links (mailto:)

Eleonora can be the program that opens mailto: links: an email address you click on a web page or in another program starts a new message in Eleonora, with the address, any Cc and Bcc, the subject, and the text the link carries. Nothing is sent until you choose Send. Links in your mail do the same.

To choose Eleonora for mail links: on Windows, Settings ▸ Apps ▸ Default apps ▸ Eleonora, then set MAILTO to Eleonora (Windows lets no program choose itself); on the Mac, Mail ▸ Settings ▸ General ▸ Default email reader ▸ Eleonora; on Linux, your desktop's default applications settings (Eleonora's .deb and .rpm offer it).
